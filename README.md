# DOPOSoccer — Entrega final (V3)

Proyecto final POOB 2026-2. Juego de fútbol 1 vs 1 en Java 21 + Swing.

## Estructura

| Carpeta / archivo | Contenido |
|---|---|
| `DOPOSoccer/` | Código fuente (`src/`), recursos (`assets/`), JUnit (`lib/`), scripts `run` / `test` y arquitectura (`docs/`) |
| `Diagramas/DOPOSoccer.asta` | Modelo Astah (clases, pruebas y secuencia) |
| `Diagramas/*.png` | Diagrama de clases y diagrama de pruebas |
| `Diagramas/Secuencia/` | Diagramas de secuencia DS01–DS14 |
| `Retrospectiva.md` | Retrospectiva del equipo |

## Ejecutar

```
cd DOPOSoccer
run.bat      # Windows  (./run.sh en Linux/Mac)
test.bat     # pruebas  (./test.sh)
```
